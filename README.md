🧮 Python Calculator Pro

A smart, feature-rich command-line calculator built using Python. This project performs multiple mathematical operations with input validation, error handling, and calculation history.

🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Modulus
- 🔢 Power calculation
- ➗ Floor division
- 📜 Calculation history
- 🛡️ Input validation
- ⚠️ Division-by-zero protection
- 🔄 Continuous calculations
- 🚪 Easy exit option

🛠️ Technologies Used

- Python 3
- Math Module
- Datetime Module

💻 How to Run

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/Python-Calculator-Pro.git

2. Open the project folder

cd Python-Calculator-Pro

3. Run the calculator

python calculator.py
